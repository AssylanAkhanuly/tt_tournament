# Диаграммы

Диаграммы как код на [D2](https://d2lang.com). Исходники — `*.d2`, результат —
`out/*.svg` и `out/*.png`.

## Зачем D2, а не Excalidraw

Раскладку делает **движок**, а не человек. В Excalidraw координаты каждого
прямоугольника и каждой стрелки считаются вручную — отсюда кривые отступы и
наезжающие подписи. Здесь я описываю только **связи**, а где что стоит и как
обвести стрелку решает layout-движок.

Плюсом: диаграмма — это текст, она живёт в гите, правится в PR и диффается.

## Сборка

```powershell
powershell -ExecutionPolicy Bypass -File diagrams/build.ps1
```

Требуется:

- **D2** — `winget install Terrastruct.D2`
- **Brave** (или любой Chromium) — только для PNG. Собственный PNG-экспорт D2
  тянет Playwright, а его CDN сейчас отдаёт 404, поэтому PNG снимается
  headless-браузером.

### Если собираете на Linux без браузера

Headless Chrome падает, когда полотно большое (у `flow-tournaments` это
2355×8058 — при таком окне процесс валится с trace trap; 800×600 снимается
нормально). Обходной путь без браузера — рендерить растр через **resvg**, но
тогда шрифт должен быть один и тот же на обоих концах, иначе D2 считает ширину
рамок по своим метрикам, а resvg рисует текст другим шрифтом, и подписи вылезают
за рамки:

```bash
F=/usr/share/fonts/truetype/liberation
d2 --layout=dagre --theme=0 --pad=40 \
   --font-regular $F/LiberationSans-Regular.ttf \
   --font-bold    $F/LiberationSans-Bold.ttf \
   --font-italic  $F/LiberationSans-Italic.ttf \
   flow-tournaments.d2 out/flow-tournaments.svg
# затем @resvg/resvg-js с fontFiles на те же три файла
```

Так собран `out/flow-tournaments.*`: шрифт там Liberation Sans, а не штатный
шрифт D2. Пересборка через `build.ps1` на Windows приведёт его к общему виду.

## Два движка раскладки, и это не косметика

| Файл | Движок | Почему |
|---|---|---|
| `architecture` | **elk** | ортогональная маршрутизация, красиво на DAG-ах |
| `domain`, `roles` | **dagre** | см. ниже |
| `flow-*` | **dagre** | держит направление сверху вниз, когда в графе **есть циклы** |

`roles` переведён с elk на dagre: с подписями на четырнадцать ролей ELK делает
несколько рамок уже собственного текста, и подписи налезают на соседние узлы.
Тот же файл на dagre раскладывается правильно.

**ELK — послойный движок: цикл он ломает разворотом ребра.** Во флоу судьи стола
четыре петли (отмена розыгрыша, следующая партия, смена сторон, следующий матч) —
на ELK схему переворачивало вверх ногами: вход оказывался внизу. dagre в той же
ситуации направление сохраняет.

По той же причине в `architecture.d2` **нет обратного ребра** «счёт в реальном
времени → клиенты»: оно замыкало цикл и переворачивало всю схему. Смысл живёт
подписью на узле.

## Что где

| Диаграмма | Что показывает |
|---|---|
| `architecture` | клиенты → шлюз → авторизация → сервисы → движок → данные |
| `domain` | доменная модель, ERD с ключами |
| `roles` | четырнадцать ролей по перечню федерации: кто кого заводит, кто судит, кто заявляет |
| `flow-tournaments` | сценарий по каждому турниру календаря: семь колонок — восемь главных стартов, Евразийская лига (муж./жен.) и открытые турниры. Заменил прежний `flow-tournament-full` |
| `flow-roles` | рабочий путь каждой из четырнадцати ролей: с какого экрана начинает, что нажимает, чего не может. Подробности — ROLES.md |
| `flow-lifecycle` | жизненный цикл турнира, сквозь все роли |
| `flow-adm` · `flow-psk` · `flow-head` · `flow-coach` | микрофлоу управляющих ролей: администратор системы, председатель судейской коллегии, главный судья, тренер — рядом, потому что сцеплены |
| `flow-table-judge` | судья стола: розыгрыши, партии, подача, смена сторон |
| `flow-offline` | обрыв сети — идёт параллельно всему циклу судьи |
| `flow-player` | игрок: заявка, свой матч, аналитика |

## Правки

Цвета и стили — в `_theme.d2`, он подключается во все диаграммы через
`...@_theme`. Поменяешь там — поменяется везде.
