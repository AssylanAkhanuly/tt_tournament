# Виджет «Сетка» (bracket) — React Native

Визуализация турнирной сетки на **react-native-skia** (нативный GPU-canvas) с
жестами (**gesture-handler** + **reanimated**): пан и пинч-зум. Решение — из
`ARCHITECTURE.md` → «Отображение сеток».

## Файлы
- `../../entities/bracket/model.ts` — **платформо-независимая модель + раскладка**
  (`layoutSingleElimination`). Общая с вебом (React Flow берёт те же данные) —
  различается только отрисовка. Чистый TS, тестируемо.
- `../../entities/bracket/sample.ts` — демо-данные (олимпийка на 8).
- `BracketCanvas.tsx` — Skia-рендерер: узлы-матчи (карточка, аватар, имена, счёт,
  подсветка победителя, LIVE), коннекторы-локти, подписи кругов; жесты пан+пинч →
  `transform` Skia-группы через reanimated shared values.

## Запуск (на устройстве/симуляторе)
Skia рисует нативно, поэтому нужен **dev-build** (не Expo Go), он у нас и так нужен
из-за пуша:
```
cd mobile
npx expo run:ios      # или run:android
# затем щипок = зум, перетаскивание = панорама
```
`App.tsx` уже показывает демо-сетку.

## Заметки
- Шрифт: бандлим **Inter (OFL)** и грузим через `useFont(ttf)` — у Skia нет
  системных шрифтов, а бандл даёт одинаковую типографику на всех платформах
  (и кириллицу).
- Жесты: пан (1 палец), focal-пинч (2 пальца, зум вокруг точки касания) и
  кнопки ＋/1:1/− (надёжный зум на эмуляторе). Пинч зумит вокруг фокуса,
  зафиксированного в начале жеста — иначе на отрыве пальцев сетку «дёргает».
- Форматы: пока олимпийка (`single_elimination`). Двойное выбывание/консолация —
  добавляются новыми функциями раскладки поверх той же модели. Группы/круговая —
  таблицей (отдельный компонент, не дерево).
- Раскладка проверяется headless-рендером ядра в SVG (см. историю разработки).
