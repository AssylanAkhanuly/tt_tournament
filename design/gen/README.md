# Пайплайн макетов: ChatGPT рисует → Claude собирает Storybook

Разделение труда:

```
 бриф (briefs/*.md)                      ┌── картинка не идёт в прод ──┐
      +                                  │  текст может быть кривой —  │
 арт-дирекшн (context.md)                │  это ОРИЕНТИР, не финал     │
      │                                  └─────────────────────────────┘
      ▼                                                 ▲
 gen/design.mjs ──► OpenAI gpt-image-1 ──► out/mockups/<name>-vN.png
                    (ИДЕЯ: композиция,                  │
                     палитра, направление)              │  Claude смотрит PNG
                                                        ▼
                              настоящий компонент Storybook
                              src/<Screen>.tsx + .module.css + .stories.tsx
                              (чёткий текст, реальные токены, рабочий код)
```

**Почему так.** Модель-картинка (gpt-image-1) отлично придумывает вид, но
искажает текст и не держит одинаковыми компоненты между экранами. Поэтому её
вывод — визуальный ориентир. Точный, чистый, кодовый вариант делает Claude:
переносит идею в Storybook как React-компонент по дизайн-токенам.

## Ключ OpenAI

Ключ НИКОГДА не в репозитории. Прежний ключ был вставлен в чат — он
скомпрометирован, его надо перевыпустить. Новый — только через env или файл:

```powershell
$env:OPENAI_API_KEY = "sk-..."                 # вариант 1: переменная
$env:OPENAI_KEY_FILE = "C:\...\scratchpad\gen\.key"   # вариант 2: файл вне репо
```

## Запуск

```bash
# 1. ChatGPT рисует ориентир (3 варианта, портрет телефона)
node gen/design.mjs player-home --n 3 --quality high

#    → gen/out/mockups/player-home-v1.png … v3.png

# 2. Claude смотрит выбранный PNG и собирает компонент Storybook.
#    Результат виден вживую:
npm run storybook
```

Флаги: `--n <1-10>`, `--size 1024x1536|1024x1024|1536x1024`,
`--quality low|medium|high`.

## Новый экран

1. Напиши бриф `briefs/<name>.md` (что за экран, блоки сверху вниз, тон).
2. `node gen/design.mjs <name>` — получишь PNG-ориентиры.
3. Попроси Claude: «собери <name> в Storybook по этому мокапу».

## Файлы

- `context.md` — общий арт-дирекшн (продукт, тёмная тема iOS, токены). Идёт в
  начало каждого промпта.
- `frame.css` — общие классы кодовых бордов (телефон, таб-бар, строка матча…),
  чтобы компоненты были одинаковыми на всех экранах.
- `boards/*.html` — кодовые борды (то, что получается после переноса в код).
- `design.mjs` — генератор картинок-ориентиров.
- `briefs/*.md` — брифы экранов.
- `out/` — результаты рендера (в `.gitignore`).
