# Art direction — общий контекст для всех макетов

Этот текст подставляется в начало КАЖДОГО промпта генерации. Он описывает
продукт и визуальную систему, чтобы модель рисовала макеты «в стиле», а не
случайную картинку. Значения ниже — из `design/src/tokens.css` (единый источник).

## Продукт
Мобильное приложение для организации турниров по настольному теннису Федерации
настольного тенниса Республики Казахстан (ФНТ РК). Пользователи — игроки, судьи,
организаторы, тренеры. Приложение на React Native (iOS/Android). Весь интерфейс
на РУССКОМ языке.

## Устройство
iPhone, вертикальная ориентация, реалистичный системный статус-бар (время 9:41,
сеть, батарея), скругление корпуса. Показывай ОДИН экран приложения крупно,
как чистый UI-скриншот (не фото телефона в руке, без фона рабочего стола).

## Визуальная система (дизайн-токены)
- Акцент / основной: синий `#2563eb`, текст на нём белый.
- Успех / подтверждение: зелёный `#10b981`.
- Фон экрана: очень светлый холодный `#f6f8fc`.
- Карточки/поверхности: белые `#ffffff`, мягкая тонкая тень, граница `#e6ebf3`.
- Основной текст: почти чёрный `#0f172a`. Второстепенный: серо-синий `#64748b`.
- Чип/бейдж: светло-синяя заливка `#eff4ff` с синим текстом.
- Скругления: 10px мелкие, 16px карточки, 24px крупные блоки.
- Отступы щедрые (шаг 4/8/12/16/20/28), много воздуха.
- Шрифт: системный без засечек (San Francisco / Segoe UI), не декоративный.

## Тон и композиция
Чисто, современно, плоско (flat), гибрид iOS + Material. Профессионально и
доверительно — это спортивная федерация, не игрушка. Компоновка карточками.
РОВНО ОДНА основная синяя кнопка действия внизу экрана. Иконки простые линейные.
Без тяжёлых градиентов, без стоковых фото, без 3D, без неона.

## Текст на макете
Подписи должны быть на русском и короткими (реальные слова: «Записаться»,
«Заявка», «Турнир», «Рейтинг», «Судья»). Модель может исказить длинный текст —
поэтому меньше мелкого текста, крупные понятные блоки и кнопки.
