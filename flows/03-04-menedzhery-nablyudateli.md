# 3 и 4 · Менеджеры-наблюдатели — флоу по экранам

Роль 3 — **менеджер по спортивной работе**, роль 4 — **менеджер по организации
соревнований**. *Полный доступ ко всем модулям без возможности редактирования
данных* ([TZ.md](../TZ.md) §2). Устройство — десктоп. Сводка —
[ROLES.md](../ROLES.md) §3–4.

**В документе федерации обе роли описаны дословно одинаково** (⚠ 12.2 — одна
это роль или две). Пока вопрос открыт, у обеих один и тот же набор экранов и
один флоу; разделение по смыслу названий (спортивная часть против
организационной) правами не закреплено — закладывать его в дизайн нельзя.

Маршрут: Э0.1 Вход → **Э3.1 Обзорная панель** → любой модуль системы в режиме
чтения (Э3.2) → Э3.3 Подписки ✳.

---

## Правило, из которого следует весь дизайн роли

**Ни одной кнопки, меняющей данные.** Ни «сохранить», ни «утвердить», ни
«отклонить», ни отметки оплаты. Это не «админ без некоторых кнопок», а
отдельный класс прав: право на чтение и право на запись проверяются раздельно
([ARCHITECTURE.md](../ARCHITECTURE.md)). Для дизайна это значит:

- каждый экран из списка Э3.2 — **вариант чтения** соответствующего экрана
  пишущей роли: те же списки, колонки и карточки, но без кнопок действий;
- вместо кнопок действий везде доступны: фильтр, поиск, открытие карточек,
  **выгрузка / печать** ✳;
- недоступное действие не показывается вовсе — не «серая кнопка», а её
  отсутствие ✳.

## Э3.1 · Обзорная панель

- **Как попадает:** первый экран после входа.
- **Что на экране:** те же зоны, что на Панели Федерации (Э1.1): «Требует
  внимания», «Ближайшие старты», «Сегодня идут» — но карточки-счётчики ведут в
  списки на чтение, а кнопки «Завести соревнование» нет.
- **Действия:** переход в любой модуль, выгрузка сводки ✳.

## Э3.2 · Модули в режиме чтения

- **Как попадает:** меню — то же, что у администратора Федерации.
- **Что видно** (по матрице [ROLES.md](../ROLES.md)) — состав каждого экрана
  описан у пишущей роли, здесь — только чтение:

| Модуль | Экран-источник | Что видно |
|---|---|---|
| Календарь сезона | Э1.2 | все категории, все состояния |
| Карточка турнира | Э1.3 | регламент, заявки, сетка, расписание, наряд, протокол, журнал турнира |
| Заявки участников | Э6.2 | состав заявок, решения судьи, причины отказов |
| Заявки судей | Э5.2 | заявившиеся, решение председателя ГСК |
| Ход турнира | Э6.6 | столы, счёт, задержки — без кнопок вызова |
| Итоговый протокол | Э6.7 | результаты, места; печать |
| Реестры | Э1.5 | спортсмены, судьи, тренеры, организации — без ролей и без выдачи |
| Рейтинг игроков и судей | Э0.4, Э5.5 | таблицы, журнал начислений судей |
| Взносы | Э2.1 | состояния взносов — без отметки оплаты |
| Команды Лиги и таблицы | Э13.3 | дивизионы, составы, таблицы туров |
| Заключения инспекции | Э10.4 | готовые заключения |

- **Состояния экрана:** пустые состояния — те же, что у экранов-источников.

## Э3.3 · Подписки ✳

- **Как попадает:** пункт меню «Мои подписки»; кнопка «Подписаться» в шапке
  карточки турнира (единственная «кнопка» роли — она не меняет данные турнира).
- **Что на экране:** список отслеживаемых соревнований: название, состояние,
  ближайшее событие; по каждому — какие уведомления приходят (смена состояния,
  протокол, отмена).
- **Действия:** подписаться / отписаться; без права вмешаться в ход.
