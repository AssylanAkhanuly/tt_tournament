# 13 · Администратор клуба — флоу по экранам

*Регистрация клуба, спортсменов, тренеров и иных лиц; подача заявок на клубные
соревнования* ([TZ.md](../TZ.md) §2). Устройство — десктоп. Область — **свой
клуб**. Самая нагруженная роль после администратора Федерации. Сводка —
[ROLES.md](../ROLES.md) §13.

Маршрут: Э0.1 Вход → **Э13.1 Мой клуб** (при первом входе — регистрация
клуба) → Э13.2 Регистрация людей; дальше две ветки: **Лига** (Э13.3) и **свои
клубные турниры** (Э13.4 → Э13.5 → Э13.6).

⚠ 12.3 — включают ли «клубные соревнования» документа Евразийскую лигу или
это две разные формы заявки; пока ветки разведены по экранам.

---

## Э13.1 · Мой клуб

- **Как попадает:** первый экран после входа.
- **Что на экране:**
  - Карточка клуба: название, город, тип (клуб / спортшкола), администратор;
    клуб числится в реестре организаций.
  - Три списка состава: **спортсмены** (ФИО, год рождения, рейтинг, взнос),
    **тренеры** (ФИО, подопечные), **иные лица** (должность).
  - Сводка: команды в Лиге, свои турниры, ближайшие события.
- **Действия:**

| Элемент | Когда | Что происходит |
|---|---|---|
| **Зарегистрировать клуб** | однократно, при первом входе | клуб попадает в реестр организаций; до этого остальные экраны закрыты |
| **Завести человека** | всегда | форма Э13.2 |
| Строка состава | всегда | карточка человека |

## Э13.2 · Регистрация людей

- **Как попадает:** Э13.1.
- **Что на экране:** форма с типом записи — **спортсмен** (ФИО, дата рождения,
  пол, разряд; привязка к клубу автоматическая), **тренер** (ФИО, подопечные),
  **иное лицо** (должность).
- **Действия:** «Завести» — человек привязан к клубу и виден в реестрах
  федерации с источником записи ✳.
- **Состояния экрана:** ⚠ 12.10 — спортсмен уже зарегистрировался сам или
  заведён регионом: как пути сходятся и кто «владелец» записи, не решено;
  дизайн формы слияния не делаем до ответа.

## Э13.3 · Команды Лиги

Евразийская лига — командная, четыре тура, дивизионы ([TZ.md](../TZ.md)
§4.10). Заявляет только клуб.

- **Как попадает:** пункт меню «Лига».
- **Что на экране:**
  - Мои команды по дивизионам: команда, дивизион (Суперлига… у мужчин шесть
    лиг, у женщин две), состояние заявки (подана / допущена), состав.
  - По команде: **календарь четырёх туров** (даты, город, статус подтверждения
    состава на тур), **таблица дивизиона** (копится по всем турам), командные
    встречи с результатами.
- **Действия:**

| Элемент | Когда | Что происходит |
|---|---|---|
| **Заявить команду в лигу** | приём заявок сезона | команда в дивизионе, ждёт допуска; ⚠ кто допускает и есть ли взнос за команду — не решено |
| **Заявить состав команды** | там же | список спортсменов клуба; ⚠ ограничения состава — вопрос 11.4 |
| **Подтвердить состав на тур** | окно перед каждым из четырёх туров | состав может меняться от тура к туру; после подтверждения — чтение |

- **Состояния экрана:** окно подтверждения не открыто — состав на чтение с
  датой окна. ⚠ Схема командной встречи, очки в таблицу, переходы между
  лигами — вопросы 11.1–11.5: экраны встречи и таблицы дальше не проектируем.

## Э13.4 · Клубные турниры — список

- **Как попадает:** пункт меню «Мои турниры».
- **Что на экране:** свои турниры (лиги клуба и любительские): название, даты,
  состояние, записалось участников, флаги значками (судьи / рейтинг / плата /
  ценз).
- **Действия:** **Завести турнир** → карточка Э13.5 в состоянии `Черновик`;
  строка → Э13.5.

## Э13.5 · Карточка клубного турнира — настройка и проведение

- **Как попадает:** Э13.4.
- **Что на экране:**
  - Регламент: название, даты, город, разряды, столы.
  - **Флаги** ([TZ.md](../TZ.md) §4.1) с умолчаниями клубного типа: судьи на
    столах (обычно нет), рейтинг (клубный турнир может идти в рейтинг),
    плата за турнир, ценз по рейтингу (не выше / не ниже порога), годовой
    взнос, документы.
  - Главный судья турнира: кто назначен (из людей клуба, неформально, без
    конкурса — §6.4).
  - Список записавшихся: игрок, рейтинг, оплата участия (если плата включена).
- **Действия:**

| Элемент | Когда | Что происходит |
|---|---|---|
| **Задать регламент и флаги** | `Черновик` | умолчания можно переопределить (§4.2) |
| **Назначить главного судью** | до публикации | человек получает роль на этот турнир |
| **Опубликовать** | регламент заполнен | открывается **свободная запись**: записался — в списке, без рассмотрения (§8.1) |
| **Отменить / перенести** ✳ | до `Завершён` | записавшиеся уведомлены |

- **Состояния экрана:** дальше турнир ведёт главный судья по своим экранам
  (Э6.x в клубном варианте: без коллегии, счёт вводит сам — §6.4); админ клуба
  видит ход и результаты.

## Э13.6 · Платежи клуба

- **Как попадает:** Э13.5, вкладка «Оплата»; пункт меню.
- **Что на экране:** по турниру с включённой платой: участник, состояние
  (оплачено / не оплачено), кто отметил, дата. Это **плата клуба за участие**,
  отдельная от годового взноса федерации (§9.3); экономист федерации её видит,
  но не ведёт.
- **Действия:** **Отметить оплату участия** / снять с причиной ✳ — в журнал.
- **Состояния экрана:** плата выключена — вкладки нет.
