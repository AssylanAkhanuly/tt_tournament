# Флоу по ролям — поэкранная детализация

Маршрут каждой из четырнадцати ролей ([TZ.md](../TZ.md) §2), где **каждый узел
флоу описан как будущий экран**: что человек видит, из чего экран состоит, что
можно нажать и куда это ведёт. Эти описания — прямой вход для дизайна
(`design/`): один узел = один экран или одно состояние экрана.

Краткая сводка по ролям (права, категории, «чего не может») — в
[ROLES.md](../ROLES.md). Маршруты в картинках — `diagrams/out/flow-roles.svg`;
коды экранов на схеме и здесь совпадают.

**Смотреть в браузере:** раздел **Флоу** в Storybook (`cd design && npm run
storybook`, опубликовано на https://storybook-static-nu-two.vercel.app) — те же
маршруты, где **каждый экран открывается отдельной страницей**, а по флоу можно
ходить кликом. Содержание берётся из этих файлов: правим здесь →
переносим в `design/src/flows/data/roleNN.ts` (см. `design/README.md`).

## Контур: только документы федерации

Решение от 11.08.2026: флоу следуют **только присланным документам федерации** —
перечню календаря и таблице «Роли и их функционал». В календаре три категории:

1. **Главные республиканские старты** — восемь (Чемпионат РК, Молодёжный,
   пять возрастных «г.р. и моложе», Кубок РК); заявляет старший тренер региона.
2. **Евразийская лига** — командная, 4 тура: мужская — Суперлига и 2–6 лиги,
   женская — Суперлига и 2 лига; заявляет администратор клуба.
3. **Открытые республиканские турниры** — спортсмен заявляется сам.

**Вне контура до отдельного решения:** клубные турниры (внутриклубные лиги,
любительские, свободная запись, плата клуба за участие) и ход турнира **без
судей на столах** ([TZ.md](../TZ.md) §6.4, §8.1) — в этих флоу их нет; в ТЗ
они остаются как замысел системы. Везде ниже судья на столе есть, счёт ведёт
он, итоговый протокол утверждает председатель ГСК.

## Как читать файл роли

Каждый экран — раздел с кодом `Э<роль>.<номер>` (Э6.2 — второй экран главного
судьи). Внутри раздела всегда одни и те же блоки:

- **Как попадает** — откуда на экран приходят: пункт меню, переход с другого
  экрана, уведомление.
- **Что на экране** — состав по зонам: шапка, списки с конкретными колонками,
  карточки с конкретными полями, бейджи и счётчики. Это и есть содержимое
  будущего макета.
- **Действия** — таблица: элемент → когда он доступен (обычно состояние
  турнира) → что происходит → куда ведёт.
- **Состояния экрана** — как экран выглядит, когда данных нет, когда идёт
  ожидание чужого решения, когда действие недоступно. Пустое состояние — тоже
  макет.

Пометки — те же, что в [ROLES.md](../ROLES.md): **✳ наше решение**, требует
подтверждения федерацией; **⚠ открытый вопрос**, дальше описанного проектировать
нельзя. Всё без пометки — из документа федерации или ТЗ.

## Сквозные экраны — есть у каждой роли

Чтобы не повторять в четырнадцати файлах, общие экраны описаны один раз здесь.
В файлах ролей они упоминаются по кодам Э0.x.

### Э0.1 · Вход

- **Что на экране:** поля логина и пароля; ссылка «забыли пароль»;
  переключатель языка (RU / KZ / EN) — он есть на каждом экране системы.
  У судьи дополнительно — вход по короткому коду ([TZ.md](../TZ.md) §6): крупное
  поле на несколько знаков, чтобы войти с планшета за столом без набора пароля.
- **После входа:** человек попадает на первый экран своей роли (Э<роль>.1).
  Если у человека несколько ролей (администратор клуба А + судья турнира Б +
  спортсмен) — экран выбора контекста: список ролей с областью каждой
  («Судья · Кубок РК · до 12.10»), выбор запоминается, переключатель остаётся
  в шапке. ✳
- **Состояния:** неверный пароль — ошибка под полем; роль истекла (срок роли
  прошёл) — роли нет в списке, история действий сохраняется.

### Э0.2 · Свой профиль

- **Что на экране:** фото, ФИО, контакты, язык интерфейса; список своих ролей
  с областью и сроком (только чтение — роли выдаёт администратор Федерации);
  смена пароля.
- **Действия:** править свои контакты и фото; всё остальное — чтение.

### Э0.3 · Уведомления

- **Что на экране:** лента уведомлений: значок типа, текст, время, ссылка на
  экран, к которому уведомление относится (заявка, матч, протокол). Непрочитанные
  выделены, счётчик — в шапке.
- **Перечень событий** — [TZ.md](../TZ.md) §10.1: решение по заявке на
  судейство; заявка принята/отклонена; пара вызвана на стол; протокол
  утверждён/возвращён; турнир завершён, рейтинг пересчитан; турнир отменён или
  перенесён.
- ⚠ Куда именно приходят уведомления ролям без приложения (браузер, почта) и
  можно ли их отключать — не решено (QUESTIONS 11). Приложение есть только у
  спортсмена.

### Э0.4 · Публичные страницы (доступны и без входа)

Роли нет — это отсутствие роли ([TZ.md](../TZ.md) §3). Видны всем, в том числе
каждой роли выше:

- **Главная сайта** — ближайшие и текущие турниры, матчи в реальном времени,
  лидеры рейтинга, новости.
- **Страница турнира** — состав, сетка, расписание, результаты, счёт в
  реальном времени, трансляция.
- **Рейтинг игроков** — таблица с фильтрами, постранично до 500 строк.
- **Рейтинг судей** — публичная таблица (§7.2).
- **Профиль игрока** — рейтинг, статистика, история матчей.
- **Новости** — на трёх языках.

Всё дальше — только через вход. ⚠ 12.9 — подтвердить, что публичная часть
действительно открыта без входа.
