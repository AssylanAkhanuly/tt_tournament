# Национальная команда

Подсистема ✳ (19.11.2026, решение владельца продукта: «врачи, которые ведут
контроль здоровья сборной, и тренер, который составляет план подготовки»).
Роли — [ROLES.md](ROLES.md), 11 (главный тренер национальной команды) и 21
(врач сборной); поэкранный флоу — [flows/11-glavnyy-trener-sbornoy.md](flows/11-glavnyy-trener-sbornoy.md),
экраны Э11.1, Э11.2, Э11.5. Открытые вопросы — [QUESTIONS.md](QUESTIONS.md)
§20 (20.1, 20.7, 20.8). Код — приложение `back/national/`, на фронте
`front/src/{entities,widgets}/national`, `views/national`, `views/national-doctor`.

## Зачем отдельная ветка

У сборной три вещи, которых нет у турнира и рейтинга: **состав** (кто в
сборной, основной или расширенный, какая возрастная группа), **медицинская
карта** (допуск, УМО, болезни, травмы, ограничения нагрузки — круглый год, а
не на один турнир) и **план подготовки** на период. Член сборной — это
спортсмен с рейтинговой карточкой: имя, год, регион и рейтинг берутся из неё и
здесь не дублируются.

Врач сборной (21) — не врач соревнований (18). Тот ставит допуск на один
турнир по справке 027/у или DamuMed; медкарта сборной этот допуск **не
заменяет** и в допуск заявки на турнир ([ADMISSION.md](ADMISSION.md)) не
подключена.

## Кто что может

| | Главный тренер (11) | Врач сборной (21) |
|---|---|---|
| Состав: смотреть | да | да |
| Состав: внести, перевести, убрать | да | нет |
| План подготовки | ведёт: период, цель, пункты, отметка «выполнено» | не видит ✳ |
| Медкарта: допуск и действующие ограничения нагрузки | читает | ведёт |
| Медкарта: диагнозы, заключения, подробности, история | **не отдаётся** | ведёт |

Кто ведёт карты — решение совещания 04.11.2026 (врачи сборной). **Кто их
читает, федерация не сказала** (QUESTIONS 20.1): разбивка «тренеру — допуск и
нагрузка, без диагнозов» взята из флоу Э11.2 и остаётся **нашим допущением**
✳. Что врач планов не видит — тоже наше ✳: право не названо, а лишнее чтение
медицинских данных опаснее лишнего запрета.

**Кто составляет план.** Совещание 04.11.2026 решило: план составляет
**личный тренер** спортсмена, согласует главный тренер. Владелец продукта
19.11.2026 поставил задачу «тренер составляет план», и в первой версии план
ведёт **главный тренер** целиком, без согласования. Личного тренера и
согласования пока нет (см. «Чего ещё нет»).

## Слои

- `models.py` — `NationalTeamMember` (один на спортсмена; `squad` — основной /
  расширенный, `age_group` — кадеты / юноши / взрослые), `MedicalRecord`,
  `TrainingPlan`, `PlanItem`.
- `services.py` — права и правила; ручки (`views.py`) только переводят их в
  HTTP. Ошибка — `NationalError(detail, status)`.
- Роли — `Role.KIND_NATIONAL_HEAD_COACH`, `Role.KIND_NATIONAL_DOCTOR`
  (область — вся система). Заводят `manage.py create_national_head_coach` и
  `create_national_doctor` (`--email --name --password`): по ROLES.md роль
  выдаёт администратор федерации, экрана выдачи ролей пока нет.

## Правила

- **В сборную** вносится только спортсмен с рейтинговой карточкой, один раз.
  Кандидаты — карточки, ещё не в сборной, по убыванию рейтинга.
- **Допуск** — запись вида «Медицинский допуск» со сроком; срок обязателен.
  Действует последний по дате: срок не прошёл — `ok`, прошёл — `expired`,
  записей нет — `none`. В составе и в шапке карточки — значок «До ДД.ММ.ГГГГ» /
  «Истёк …» / «Не внесён».
- **Ограничение нагрузки** — поле `load_limit` у травмы, болезни или
  постоянного ограничения. Действует, пока не прошла дата «Действует до»;
  без даты — бессрочно. Главный тренер видит только действующие.
- «Действует до» раньше даты записи — 400.
- **План** — период (начало не позже окончания) и цель; пункты — работа, сбор
  или старт, срок, отметка «выполнено». Текущий план — тот, чей период
  включает сегодня, иначе последний по началу; в составе он показан **долей
  «N из M»** (флоу Э11.1: план, выполнение которого нельзя проверить, —
  список пожеланий).

## Ручки (`/api/national/`)

| Ручка | Кто | Что |
|---|---|---|
| `GET members/` | тренер, врач | состав: человек, состав, группа, допуск, число ограничений; тренеру ещё `plan` |
| `POST members/` | тренер | `{user_id, squad, age_group}` |
| `GET members/candidates/?q=` | тренер | кого можно внести |
| `GET` / `PATCH` / `DELETE members/<id>/` | тренер, врач / тренер / тренер | член сборной; `{squad, age_group}` |
| `GET members/<id>/medical/` | врач — всё (`full: true`, `records`); тренер — `full: false`, `clearance`, `limits` | медкарта |
| `POST members/<id>/medical/` | врач | `{kind, date, until, title, note, load_limit}` |
| `DELETE medical/<id>/` | врач | удалить запись |
| `GET` / `POST members/<id>/plans/` | тренер | планы; `{starts_on, ends_on, goal}` |
| `PATCH` / `DELETE plans/<id>/` | тренер | правка периода и цели, удаление |
| `POST plans/<id>/items/` | тренер | `{kind, title, due}` |
| `PATCH` / `DELETE plan-items/<id>/` | тренер | `{done}`, удаление |

## Экраны

- **Главный тренер — `/national`**: «Состав сборной» (таблица, поиск,
  «Внести в сборную»); строка — `/national/members/<id>/plan|medical`: шапка
  (фамилия, год и регион, рейтинг, допуск; состав и группа — выбором там же,
  «Убрать из сборной»), «План подготовки» (период, цель, «N из M», пункты с
  отметкой, «Пункт плана», «Новый план») и «Медкарта» (действующие
  ограничения нагрузки).
- **Врач — `/doctor`**: тот же состав без правки и без колонки плана; строка —
  `/doctor/members/<id>`: шапка и медкарта целиком, «Добавить запись»,
  удаление записи с подтверждением.

## Чего ещё нет

- **Личного тренера и согласования плана** (совещание 04.11.2026: составляет
  личный тренер, согласует главный, «Вернуть с комментарием» — Э11.5).
- **Календаря подготовки** (Э11.3) и **рапортов на командирование** (Э11.4):
  пункты «сбор» и «старт» вводятся руками, а не выбираются из календаря.
- **Тренера-консультанта** (19 — копия главного тренера), **тренеров сборной**
  по возрастам (20) и **психолога сборной** (22, спортивная карточка).
- **Истории подготовки** (УТС, выезды, результаты лентой — Э11.2).
- Правила выполнения пункта (явка на сбор, результат старта) — только отметка
  тренера (QUESTIONS 20.8). Правило перевода между основным и расширенным
  составом — решением тренера (QUESTIONS 20.7).
- Связи медкарты с допуском на турнир.
- Мобильного приложения для этих ролей.
