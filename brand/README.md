# Логотипы SpinCoach

Знак и словесный знак в двух компоновках и двух темах.

## Что как называется

**`dark` — это версия ДЛЯ тёмного фона** (знак белый), `light` — для светлого
(знак `#09091A`). Не наоборот.

| Файл | Что это |
|---|---|
| `mark-dark.svg` · `mark-light.svg` | только знак |
| `logo-horizontal-*.svg` | знак слева, слово справа |
| `logo-vertical-*.svg` | знак сверху, слово под ним |
| `png/` | растр 256…4096 px под каждую версию |
| `png/preview-*` | превью на фирменной подложке, для проверки, не для вёрстки |
| `source-logo_vector.svg` | исходный вектор знака, из которого всё собрано |

## Что важно знать

**Берите SVG.** Они самодостаточны: знак векторный, а слово переведено в кривые,
поэтому шрифт на чужой машине не нужен и текст не поедет. PNG лежат для тех
мест, где вектор не принимают.

**У исходника есть подвох.** В `source-logo_vector.svg` у корня стоит
`fill="none"`, а у пути своей заливки нет, поэтому файл как есть отрисовывается
пустым. В наших сборках заливка проставлена явно.

**Шрифт — Outfit Light** (SIL Open Font License, свободный). Ближайший аналог
Avenir Next Light, который просился по стилю, но он коммерческий (Linotype) и в
репозиторий его класть нельзя. У Outfit такие же круглые геометричные чаши, и
они рифмуются с окружностью в знаке.

**Кегль слова заметно меньше высоты знака.** Это не ошибка: у знака тонкая линия
и много воздуха от диагонали, поэтому при равной высоте слово перевешивает.

## Пересборка

Комплект собирается скриптом из `source-logo_vector.svg` и файла шрифта. Если
меняется знак или компоновка, пересобирайте всё разом, а не правьте отдельные
файлы руками: иначе версии разъедутся.
