# Логотип ФНТ РК

Официальный знак федерации (щит с орнаментом, солнце с беркутом и надпись
`TTFRK`). Прислан федерацией в CorelDRAW, здесь лежит в вебовых форматах.

| Файл | Что это |
|---|---|
| `fnt-logo.svg` | вектор, основной файл — берите его |
| `fnt-mark.svg` | компактная марка для мелких мест (см. ниже) |
| `fnt-logo.cdr` | исходник CorelDRAW X8, как прислали |
| `png/fnt-logo-*.png` | растр 256…2048 px по ширине, фон прозрачный |
| `png/fnt-mark-*.png` | растр марки 64…512 px, фон прозрачный |

## Что важно знать

**Берите SVG.** Он самодостаточный: 45 кривых, ни шрифтов, ни встроенных
картинок — надпись `TTFRK` уже в кривых, поэтому на чужой машине ничего не
поедет. PNG лежат для мест, где вектор не принимают.

**Два цвета:** синий `#007CC3` (щит) и жёлтый `#FFEC00` (всё остальное).
В исходнике цвета заданы в CMYK, при конвертации переведены в sRGB.

**Пропорция 130.28 × 184.16** (≈ 46 × 65 мм, отношение 0.707). Знак вертикальный,
под горизонтальную шапку его надо либо ужимать по высоте, либо ставить рядом с
текстом отдельно — горизонтальной компоновки федерация не присылала.

**Щит не работает мелким — для этого есть марка.** `fnt-mark.svg` — квадратная
плитка цвета щита, внутри «тройка», солнце и беркут; ленты орнамента и надписи
TTFRK нет. Ниже 30 px они всё равно схлопываются в шум, а марка держится до
16 px. Собрана из тех же кривых, ничего не перерисовывалось: взяты пути эмблемы,
скругление плитки — те же 12.36 % стороны, что у настоящего щита. Правило «крупно
герб, мелко упрощённый знак» снято с 82 референсов, разбор — в
`design/REFERENCES.md` и в Storybook, «Дизайн-система → Референсы».

**Выворотки нет.** Одноцветной версии под тёмный фон в исходнике не было и мы её
не рисовали. По референсам она понадобится, если появится титульный экран с
крупным знаком, — это открытая рекомендация. Не путайте с
`design/src/assets/fnt-emblem.png`: там другой, одноцветный знак без щита,
орнамента и надписи; в макетах он больше не используется, остался только в
сравнении «было / стало» на странице референсов.

**Мокапы — отдельный разговор.** По [DESIGN.md](../../DESIGN.md) в макетах не
должно быть герба и флага настоящей федерации, там нейтральное «TT Tournament».
Этот комплект — брендовый исходник, а не ассет для макетов.

## Где используется

Лента орнамента с правой стороны щита вынута из этого SVG в
`design/src/theme/ornament-logo-band.svg` и служит фоновым узором экранов
Storybook (подробности — `design/README.md`, раздел «Фоновый орнамент»).
Если знак изменят, ленту надо перевыгрузить оттуда же.

## Как получен SVG

Исходный `.cdr` — контейнер ZIP с `content/riffData.cdr` внутри; читает его
только libcdr, то есть на практике Inkscape:

```
inkscape fnt-logo.cdr --export-type=svg --export-plain-svg \
         --export-area-drawing --export-filename=fnt-logo.svg
```

Дальше файл почищен вручную: выброшен пустой текстовый объект, оставшийся от
CorelDRAW, схлопнуты две пустые группы, а их `translate` вложен в `viewBox`,
`style` переписан в атрибуты `fill`/`fill-rule`. Геометрия при этом не менялась:
рендеры до и после чистки совпадают, расхождения — только сглаживание на
контурах.
